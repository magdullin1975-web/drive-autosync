# Drive Autosync — Privacy Policy / Datenschutz / Конфиденциальность

**English.** Drive Autosync is a personal app by Eduard Magdullin. It uploads files from folders that the
user selects on his own Android device to the user's own Google Drive. It uses only the Google Drive scope
`drive.file` (access to files the app itself creates). No data is sent to the developer or any third party.
No analytics, no ads, no tracking. Upload history is stored only on the device. The user can revoke access
at any time at https://myaccount.google.com/permissions.

**Deutsch.** Drive Autosync ist eine private App von Eduard Magdullin. Sie lädt Dateien aus vom Nutzer
gewählten Ordnern seines eigenen Android-Geräts in sein eigenes Google Drive hoch (nur Berechtigung
`drive.file`). Es werden keine Daten an den Entwickler oder Dritte übertragen, keine Analyse, keine Werbung.

**Русский.** Drive Autosync — личное приложение Эдуарда Магдуллина. Загружает файлы из выбранных папок
своего устройства в свой Google Диск (доступ только `drive.file`). Никакие данные не передаются
разработчику или третьим лицам, нет рекламы и аналитики.
