# Drive Autosync

Android-приложение: само загружает новые файлы из выбранных папок телефона/планшета
на Google Диск (папка `00_Входящие/<устройство>/<папка>`). С компьютера, где стоит
Google Drive для компьютера, файлы видны как обычная папка.

## Установка
1. Откройте на телефоне раздел **Releases** этого проекта и скачайте последний файл `DriveAutosync-N.apk`.
2. Откройте файл и разрешите установку из браузера/«Моих файлов».
3. В приложении по очереди нажмите кнопки 1–3: войти в Google, доступ к файлам, батарея.
4. «＋ Добавить папку» — например Download и Pictures.

## Как работает
- Проверка каждые 15 минут и по кнопке «Синхронизировать сейчас».
- Большие файлы (> 50 МБ) по желанию — только по Wi‑Fi.
- Оригиналы на устройстве не удаляются. Изменённый файл загружается как новая версия.
- Приложение видит на Диске только файлы, которые создало само (доступ `drive.file`).
- Раз в день проверяет новую версию здесь, в Releases, и предлагает обновиться.
- Если что-то сломалось (нет входа, нет доступа, Диск заполнен, ошибки подряд, сутки без синхронизации) — присылает уведомление.

## Сборка
Каждый push в `main` собирает подписанный APK (GitHub Actions) и публикует его в Releases.
Ключ подписи хранится в секрете `SIGNING_KEY` (формат `пароль:base64-keystore`).
